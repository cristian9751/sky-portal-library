# Ladle stories

Crea archivos `*.stories.tsx` dentro de `src/stories/` para añadir ejemplos al catálogo.

- `buttons.stories.tsx`: botones y variantes.
- `forms.stories.tsx`: campos, checkbox y switch interactivos.
- `surfaces.stories.tsx`: tarjetas, alertas, badges, avatar, progreso y skeletons.
- `login-preview.stories.tsx`: preview del diseño de acceso con `AuthShell` y traducciones.

La historia del login es una demo visual: evita enviar credenciales o realizar peticiones reales.
